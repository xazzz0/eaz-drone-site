# eaz-drone-site
website for drone business
## Local development

This is a static HTML site. Install the Node dependencies with `npm install`, then run `npm run validate` to check production pages, local assets, metadata, and sitemap URLs. Use `npm run optimize:images` when updating source images.

For a local preview, serve the repository root with any static HTTP server (for example, `npx serve .`) and open the printed URL. The PowerShell scripts in `scripts/` derive the repository root from their own location; run them from PowerShell when fragment generation or refactoring is needed.
